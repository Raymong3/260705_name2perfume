# 260802 관리자 변경사항 누적 및 기록서 폼 레이아웃 개편

## 1. 개요
고객 메모와 조향사 의견을 명확히 분리하고, 관리자 대시보드에서 향료 변경 시 기존 손님의 변경 사항에 누적되어 표기되도록 로직을 수정하였습니다. 또한, 훈민향음 기록서의 하단 수순을 요청에 따라 조정하였습니다.

## 2. 세부 수정 항목

### 1) 관리자 대시보드 조향사 의견 초안 작성 자동화
- 손님이 작성한 메모는 `guestMemo` (읽기 전용) 영역에 보존.
- `조향사 의견 (Perfumer's Touch)` 란에는 이전에 적용되던 테마별 감성적 조향 소견 초안이 자동으로 pre-fill되도록 복원.

### 2) 관리자 변경사항 누적(Cumulative Diff) 로직 개선
- 기존에는 관리자가 향료를 추가/삭제할 때 원본 추천 레시피와의 차이점만 다시 계산하여 기존 손님의 변경 기록이 초기화되거나 새로 써지는 현상이 있었습니다.
- 이를 개선하여 손님이 변경한 향료 내역(`addedNotes`, `removedNotes`)에 관리자가 추가/삭제한 내역이 **상호 누적(Cumulative)**되어 `변경 사항 기입` 문구 및 데이터로 갱신되도록 수정하였습니다.
- `변경 사항 기입` 필드도 관리자가 직접 편집할 수 있도록 수정 가능 모드로 제공합니다.

### 3) 훈민향음 기록서(A6) 하단 레이아웃 수순 정리
- 기록서 하단의 표시 순서를 요청하신 직관적 레이아웃으로 변경 완료하였습니다.
  1. **`[조향 변경 이력]`** (누적된 향료 추가/제거 내역)
  2. **`[고객 메모]`** (손님이 작성한 요청 메모 - 존재 시 표기)
  3. **`[조향사 의견]`** (조향사 최종 검수 소견)
