- 메인 1페이지 좌측 브랜딩 영역의 **향수 병 사진(`perfumeImgUrl`) 블록 완전 제거** 완료.
- 1페이지 내의 `"나의 과거 기록서 보기"` 링크 제거 (상단 헤더의 항시 노출되는 '🏛️ 조향 보관소 이동' 버튼으로 일원화).

### 2. 마이페이지 계정 명칭 표출 안내 갱신
- 기존: `본인 로그인 계정(7797_scent-jasmine)으로 생성된 역대 조향 내역입니다.`
- 변경: `getDisplayGuestName(loginId)`를 적용하여 **`본인 로그인 계정 7797(자스민)으로 생성된 역대 조향 내역입니다.`** 형태로 가독성 대폭 향상.

### 3. 스텝 단계 배지 타이틀 스타일 정돈
- **1단계 (이름 입력)**: `조향 상담 - 1단계` ➔ **`1단계: 나를 읽다`**
- **2단계 (세종시 명소 선택)**: `Step 02 / 세종시의 이야기를 담다` ➔ **`2단계: 세종을 담다`**

### 4. 스텝 2, 3 및 보관소/마이페이지 전체 다크 그린 테마 일원화
- 1페이지의 **다크 포레스트 그린 (`#06100c`, `#0c1c16`, `#122920`)** 럭셔리 모드를 스텝 1 (성함 입력), 스텝 2 (세종 명소 선택), 스텝 3 (향 추천 카드 & 커스텀 조향기), 제출 완료 및 일반 손님 조향 보관소 마이페이지 전체에 통일 적용.
- 흰색(`bg-white`) 카드 및 폼 요소들을 유리모피즘 다크 포레스트 그린 패널(`bg-forest-900/90 border-forest-750 text-white backdrop-blur-lg`)로 완전 전환.
