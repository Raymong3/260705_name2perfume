## 💡 주요 개편 및 구현 내역

### 1. 메인 타이틀 수정
- 메인 1페이지 제목: `세종과 이름의 만남(조향)` ➔ **`세종의 향을 담다`** 로 변경 반영 완료.

### 2. 접수번호 4자리 & 마음에 드는 향 12종 선택 그리드 (3x4 / 4x3)
- **접수번호 체계**: 영문자 포함 조합(예: `1234a`) 제거 ➔ **휴대폰 번호 뒷자리 4자리 숫자(예: `4440`)** 로 변경.
- **마음에 드는 향 12종 선택 그리드**:
  - `favoriteScents.ts`에 12가지 베스트 향료 (베르가못, 스위트 오렌지, 유칼립투스, 그린티, 로즈, 피오니, 자스민, 로즈마리, 화이트 머스크, 샌달우드, 시더우드, 화이트 앰버) 메타데이터 구축.
  - 메인 페이지에 3x4 / 4x3 반응형 카드 그리드 형태로 배치하여 사용자가 1가지를 직관적으로 선택할 수 있도록 구현.
- **고유 식별 키 (User Key)**:
  - `[접수번호 4자리] + [선택한 향 ID]` (예: `4440_scent-bergamot`) 조합으로 유저 식별자 생성.
  - 상단 헤더에는 `접수번호: 4440 (베르가못)` 형태로 세련되게 변환 표출.

### 3. 신규 사용자 vs 기존 사용자 구분 탭 (Mode Toggle)
- **[신규 접수] 탭**:
  - `[4자리 숫번호] + [선택한 향]` 식별키가 DB/기록에 이미 존재할 경우 🚨 `"이미 사용 중인 접수 정보입니다. 다른 향을 선택하시거나 [기존 접수자 조회] 탭을 이용해 주세요."` 팝업을 띄우고 접수를 안전하게 차단.
  - 새로운 정보일 경우 신규 접수를 시작하고 1단계(이름 입력)로 이동.
- **[기존 접수자 조회] 탭**:
  - 입력된 `[4자리 숫번호] + [선택한 향]` 조합으로 기존 기록 조회 및 로그인.
  - 일치하는 기록이 없을 경우 🚨 `"등록된 접수 정보가 없습니다. 접수번호와 선택한 향을 확인하시거나 신규 접수를 진행해 주세요."` 팝업 안내.

### 4. 전체 다크 그린(Dark Green) 테마 적용
- `index.css` 배경 및 `glass-panel` 전체를 고급스러운 **다크 포레스트 그린 (`#06100c`, `#0c1c16`)** 모드로 전환.
- 헤더, 메인 접수 카드, 12종 향 선택 그리드 및 버튼 전체에 딥 포레스트 그린과 럭셔리 골드/에메랄드 톤을 적용하여 깊이감 있는 럭셔리 분위기 완성.
