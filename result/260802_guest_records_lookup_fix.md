# 260802 조향기록서 보관함 조회 및 표시 버그 수정

## 1. 문제 원인
- 고객 로그인 식별자(`1234_scent-jasmine`)와 기존 DB 저장 방식(`1234`) 간의 정확도(Exact Match) 쿼리 조건 차이로 인해, 기존 접수 조회 시 기록이 검색되지 않고 빈 화면이 노출되었습니다.
- 보관함(`GuestMyPage.tsx`)에서 접수 대기(`submitted`) 상태인 기록의 경우 `기록서 보기` 버튼이 가려져 조회가 불가능했습니다.

## 2. 세부 조치 항목

### 1) 전화번호 및 식별자 유연 검색 지원 (`supabaseClient.ts`)
- LocalStorage 및 Supabase DB 조회(`getRecords`, `dbGetRecords`) 로직 수정:
  - 식별자 전체(`1234_scent-jasmine`)뿐만 아니라, **휴대폰 뒷자리 숫자(`1234`) 기준 매칭**도 함께 조회가 수행되도록 연산 조건(`OR` 조건 및 유연 필터ing)을 확장했습니다.

### 2) 보관함 UI 기능 개선 (`GuestMyPage.tsx`)
- 접수 완료/제작 완료 상태에 상관없이 고객이 생성한 조향 기록을 바로 확인하실 수 있도록 **`기록서 보기` 버튼을 상시 활성화**하였습니다.

### 3) 신규 조향 접수 후 실시간 보관함 동기화 (`GuestMainPage.tsx`)
- 고객이 새로운 향수 조향을 신청하면 즉시 내 보관함 상태(`guestRecords`)에 실시간 반영되어, 언제든지 보관함에서 확인하실 수 있도록 하였습니다.
