# 260802 기본 향수 이름 변경 및 고객/조향사 메모 표기 개선

## 1. 개요
기본 향수 이름 표기를 `ㅇㅇㅇ의 향수`로 일관되게 정형화하였으며, 고객 작성 메모가 관리자 대시보드에 명확하게 표기되도록 데이터를 정제하고 조향사 소견 초안의 불필요한 접두어(`조향사 의견:`, `조향사메모:`)를 완전히 제거하였습니다.

## 2. 세부 변경 사항

### 1) 기본 향수 이름 지정 (`ㅇㅇㅇ의 향수`)
- `recommendPerfume.ts`: AI 기본 레시피 생성 시 이름 추천 기본값을 `[고객명]의 향수`로 지정.
- `GuestMainPage.tsx`, `useScentSession.ts`, `supabaseClient.ts`: 입력값이 없을 때의 fallback 향수 이름을 기존 `${guestName}의 향` ➔ **`${guestName}의 향수`**로 통일.

### 2) 고객 작성 메모 관리자 대시보드 출력 수정
- `AdminDashboard.tsx`: 고객 작성 메모(`guestMemo`)가 조향사 메모(`makerMemo`)에 덮어씌워지지 않고 독립적으로 선명하게 노출되도록 렌더링 조건을 보장.

### 3) 조향사 메모 접두어 제거 (`조향사 의견:` / `조향사메모:` 삭제)
- `formatters.ts`, `A6CertificatePrint.tsx`, `AdminDashboard.tsx`: 조향사 소견 초안 및 기록서 출력 시 `조향사 의견:` 접두어를 제거하고 자연스러운 문장 본문만 깔끔하게 출력하도록 정제.
