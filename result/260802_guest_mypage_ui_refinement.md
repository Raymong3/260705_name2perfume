# 260802 손님 마이페이지 UI 및 향수명 표시 문구 수정

## 주요 수정 사항

1. **게스트 포털 문구 및 헤더 수정**
   - 상단 서브 타이틀: `GUEST PORTAL` → `FRAGRANCE ARCHIVE` (브랜드 분위기에 맞는 고급스러운 폰트 및 영문 표기)
   - 메인 타이틀: `조향 기록 보관함` → `조향기록서 보관함`
   - 목록 소제목: `나의 조향 기록 목록` → `나의 조향기록서 목록`

2. **대상 이름 및 향수명 표기 형식 변경**
   - 기존: `홍길동 (세종의 아침)`
   - 변경: `홍길동(향수명: 세종의 아침)` 형태로 시각적 직관성을 향상시켰습니다.
