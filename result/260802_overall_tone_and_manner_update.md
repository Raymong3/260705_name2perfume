# 260802 전체 브랜드 톤앤매너(Tone & Manner) 일관성 맞춤 작업

## 1. 개요
훈민향음(Hunmin Scent)의 한글 정체성을 강조하기 위해 단계별 배지 명칭을 정갈한 한글 표현으로 유지하고, 전체적인 UI 문구의 톤앤매너를 깔끔하게 다듬었습니다.

## 2. 주요 변경 내역

### 1) 상단 네비게이션 (Header)
- 과거 기록 버튼: `조향기록서 보기` ➔ **`조향기록서 보관함`** (마이페이지 타이틀과 명칭 통일)

### 2) 손님 첫 메인 화면 & 로그인 (GuestMainPage)
- 브랜드 상단 태그: `HUNMIN SCENT ATELIER`
- 메인 헤더: `훈민향음 조향 여정`
- 탭 버튼: `기존 조향 기록 조회` ➔ **`조향기록서 보관함`**
- 1단계 배지: **`1단계: 나를 읽다`** (한글 브랜드 정체성 유지)

### 3) 단계별 조향 여정 (Step 2, Step 3, Step 4)
- 2단계 명소 선택 배지: **`2단계: 세종을 담다`**
- 3단계 커스텀 조향 배지: **`3단계: 향을 잇다`**
- 4단계 완료 카드 배지: **`조향 의뢰 접수 완료`**

### 4) 손님 조향기록서 보관함 (GuestMyPage)
- 메인 타이틀: **`조향기록서 보관함`**
- 목록 헤더: **`나의 조향기록서 목록`**
- 향수 명칭 표시: **`홍길동(향수명: 세종의 아침)`**
